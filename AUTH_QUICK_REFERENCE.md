## How to Use

### 1. Sign Up
```dart
context.read<AuthBloc>().add(
  AuthSignupEvent(
    email: 'user@example.com',
    password: 'password123',
    displayName: 'John Doe',
  ),
);
```

### 2. Login
```dart
context.read<AuthBloc>().add(
  AuthLoginEvent(
    email: 'user@example.com',
    password: 'password123',
  ),
);
```

### 3. Google Sign-In
```dart
context.read<AuthBloc>().add(const AuthGoogleSigninEvent());
```

### 4. Logout
```dart
context.read<AuthBloc>().add(const AuthLogoutEvent());
```

### 5. Listen to Auth State
```dart
BlocBuilder<AuthBloc, AuthState>(
  builder: (context, state) {
    if (state is AuthAuthenticated) {
      return Text('Welcome, ${state.user.displayName}');
    } else if (state is AuthLoading) {
      return CircularProgressIndicator();
    } else if (state is AuthError) {
      return Text('Error: ${state.message}');
    }
    return Text('Not authenticated');
  },
);
```

## Common Tasks

### Add new auth provider (e.g., Facebook)
1. Create usecase in `domain/usecases/facebook_signin_usecase.dart`
2. Implement in `data/datasources/firebase_auth_datasource.dart`
3. Add to repository interface and implementation
4. Add new event in `presentation/bloc/auth_event.dart`
5. Add handler in `presentation/bloc/auth_bloc.dart`

### Add email verification
1. Add method to `FirebaseAuthDatasource`
2. Create `SendVerificationEmailUsecase`
3. Add event `AuthSendVerificationEmailEvent`
4. Update UI to show verification flow

### Add password reset
1. Add method to `FirebaseAuthDatasource`
2. Create `ResetPasswordUsecase`
3. Create `ForgotPasswordScreen`
4. Add route and navigation

## Troubleshooting

### Firebase not initializing
→ Check `Firebase.initializeApp()` is called in `main()` before `runApp()`
→ Check `firebase_options.dart` has correct credentials

### Google Sign-In fails
→ Check Google Sign-In is enabled in Firebase Console
→ For Android: Verify SHA-1 fingerprint is registered
→ For iOS: Check GoogleService-Info.plist is included

### Firestore permission denied
→ Check Firestore rules allow current auth level
→ In development, use test mode
→ In production, implement proper security rules

### BLoC state not updating
→ Verify `BlocProvider` wraps the app at top level
→ Check event handlers are registered with `on<EventType>`
→ Ensure `emit()` is called within event handlers
